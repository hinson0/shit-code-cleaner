# 0001：Python 3.14 与 uv

日期：2026-09-23
状态：采纳

## 问题
协作约定要求 uv 管理且使用 Python 3.14；旧附件不能作为本地验收依据。

## 选择
保留 .python-version 的 3.14；requires-python 使用 >=3.14,<3.15。
依赖写入标准 dependency-groups，解析结果锁定在 uv.lock。
当前机器实测为 uv 0.7.6、CPython 3.14.2；未升级全局工具。

## 代价
暂不承诺其他 Python 小版本；升级时重新验证并调整版本范围。
依赖安装通过不代表产品可运行；Day 1 的实现写入受阻，见当天记录。
